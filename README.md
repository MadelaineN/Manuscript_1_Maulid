# NVI Project Template

Welcome to the (proposed) NVI Project Template. This is a repository that proposes a standard directory structure for working on data analytics projects.

-   [What is a GitHub template repository](#what-is-a-github-template-repository)
-   [The directory structure explained](#the-directory-structure-explained)

## What is a GitHub template repository 

A template repository can be used to span a new project by clicking on the "Use this template" and then "Create a new repository" button in the right corner of this screen.

<img src="https://github.com/user-attachments/assets/c0e9ce48-5054-4128-8d08-d0c65e6a2870" alt="image" width="611" height="46"/>

This will open the standard GitHub screen for creating a new repository.

<img src="https://github.com/user-attachments/assets/962ff7cb-f146-43e8-9201-26da00125acd" alt="image" width="711" height="613"/>

After you enter the name and description a new repository will be created with the following structure:

```         
┌───data
│   ├───external
│   ├───interim
│   ├───processed
│   └───raw
├───docs
├───notebooks
├───reports
│   └───figures
└───scripts
```

## The directory structure explained 

There are 5 main folders that are a part of this template. Each folder is designated to store specific data or files. This can be explained in brief as follows:

**1. data**:

This folder will hold all data that is specific to the project you have created. **Remember that raw data generally lives on shared resources in VI ecosystem (example PJS, K Drive, Sharepoint) and does not need to be copied here and can be directly accessed from those resources.** This folder will only hold data that is in addition to the data available on the shared resources. There are 4 sub-folders in this folder, the description of each is as follows:

**i. raw:** This folder should contain any raw data that will be used in your project.

**ii. external:** This folder should contain any data that has been collected from external sources for this specific project.

**iii. interim:** This folder is designated to hold intermediate datasets that is generated by your project. Generally these intermediate datasets are *.rds* or *.Rdata* files.

**iv. processed:** This folder will hold the final outputs generated by your project. If needed, you can move the data from this folder to VI shared resources (or directly save the output on shared resources).

> [!IMPORTANT]
> The data in this folder should not be committed to GitHub. After you have added any data in this folder, please ignore this folder by modifying your .gitignore file to add: `data/\*`

**2. docs:**

This folder will hold all the documentation related to your project. This folder may or may not be ignored based on the content that you add to this folder. If the folder needs to be ignored, add `docs/*` to your `.gitignore` file.

**3. notebooks**:

This folder will hold all notebooks associated with this project. In R environment, QUARTO files (.qmd) and Rmarkdown files (.Rmd) are notebooks and should therefore be a part of this folder. This folder will be committed to GitHub.

**4. reports**:

This folder is designated to store all reports generated by your project. This included all html, pdf or powerpoint generated through QUARTO or Rmarkdown. There is also a sub-folder in this folder:

**i. figures**: The figures generated by your R scripts will be stored here. This includes all graphs, plots, maps etc.

This folder will generally not be committed to GitHub and should be ignored by adding `reports/\*` to your `.gitignore` file.

**5.  scripts**:

This folder will contain all R scripts that you create as a part of this project. This folder will be committed to GitHub.

## Next Steps in RStudio

After your new repository is created with this project template you need to create a New Project in RStudio (be it your RStudio Desktop or RStudio Workbench session) and link this repository to your project. RStudio allows you to do this through it's "*Clone a project from Git repository*" option. The steps are as follows:

> [!IMPORTANT]
> This presuposes that you have set up SSH on your computer/account. If not refer to [Connecting RStudio to GitHub
](https://connect.posit.vetinst.no/nvi-tutorials/quarto_files/part_configrations/connecting_r_studio_to_github.html)(needs login to interal VI documentation), or [official GitHub documentation](https://docs.github.com/en/authentication/connecting-to-github-with-ssh).

**Step 1:** From the GitHub repository page click on the Green button that says **Code**, the click on **SSH** and copy the SHH link to this repository. 

**Step 2:** Open RStudio session and click on File &rarr; New Project &rarr; Version Control &rarr; Git. 

**Step 3:** Paste the reposttory link that you copied in Step 1 under "Repository URL". The "Project directory name" will automatically populate with the repository name, you may change it if you want. Then Browse to the location where you want to save your project and once done, click on **"Create Project"**. 

Now you have successpully started a new project in RStudio with the NVI project template.
